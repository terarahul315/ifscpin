SBI IFSC Code Finder – State Bank of India Branch IFSC, MICR & Address

State Bank of India (SBI) is India's largest public sector bank with over 22,000 branches. Every SBI branch has a unique 11-character IFSC code starting with SBIN0 followed by a 6-digit branch code.

🏦 Open SBI Branch IFSC Finder

How to Read an SBI IFSC Code (Example: SBIN0000691)

  • First 4 Letters (SBIN): Identifies State Bank of India.
  • 5th Character (0): Reserved control digit (always zero).
  • Last 6 Digits (000691): Unique SBI branch code (if your branch code is 3 or 4 digits, add zeros in front to make it 6 digits, e.g., branch code 691 becomes SBIN0000691).
