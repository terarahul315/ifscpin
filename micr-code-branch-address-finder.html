What is a 9-Digit MICR Code?

MICR (Magnetic Ink Character Recognition) is a 9-digit numeric code printed at the bottom of bank cheques (right next to the cheque number):

  • First 3 Digits: City code (aligned with the city's postal PIN prefix, e.g., 226 for Lucknow, 110 for Delhi).
  • Middle 3 Digits: Unique Bank code assigned by RBI (e.g., 002 for SBI).
  • Last 3 Digits: Specific Bank Branch code.
